# Bank IFSC Code Viewer

A modern, responsive web application to search for Indian Bank details using their IFSC code.

## Features

- **Modern UI**: Designed with latest Bootstrap 5 and Glassmorphism aesthetics.
- **Fast Search**: Instant results using the Razorpay IFSC API.
- **Responsive**: Fully optimized for mobile, tablet, and desktop screens.
- **Lightweight**: Built with Vanilla JavaScript (No jQuery or heavy libraries).

## Technologies Used

- HTML5
- CSS3 (Custom Glassmorphism & Animations)
- Bootstrap 5.3
- Vanilla JavaScript (ES6+)
- Razorpay IFSC API

## How to Use

1. Open `ifsc.html` in your web browser.
2. Enter a valid 11-digit IFSC code (e.g., `SBIN0000001`).
3. View the bank details instantly in a beautiful card card.
